# Model endpoints mockups

These are the wireframes the user approved on 2026-09-27 while designing model endpoints (spec: `../2026-09-27-model-endpoints-design.md`). They're HTML fragments that were shown inside the brainstorming companion's frame. Opened on their own, their inline styles still render, but the frame's `.cards` / `.card` layout doesn't.

- `picker.html`: the model picker with several endpoints. **Option B was chosen:** endpoint chips under the search box, a section per endpoint, and the current model's endpoint first.
- `settings-endpoints.html`: endpoints in Settings → Models, plus the Add endpoint dialog. **Option B was chosen:** a master–detail layout, with endpoints, "ollama.com account" and "Defaults" on the left, and the selected endpoint's settings and its models table on the right.

The spec's "UI" section is the source of truth. The mockups show layout, not final styling.
